# ClinicalThai

ค้นหางานวิจัยทางการแพทย์ที่เปิดรับอาสาสมัครในประเทศไทย และดูภาพรวมงานวิจัยสำหรับนักวิจัย
ข้อมูลทั้งหมดดึงจาก [ClinicalTrials.gov API v2](https://clinicaltrials.gov/data-api/api) โดยกรองเฉพาะงานวิจัยที่มีศูนย์วิจัยในไทย

**เว็บจริง:** https://clinical-lake.vercel.app

## ฟีเจอร์

### ฝั่งอาสาสมัคร
| หน้า | ใช้ทำอะไร | ทำงานอย่างไร |
| --- | --- | --- |
| `/trials` ค้นหางานวิจัย | ค้นหาด้วยชื่อโรคภาษาไทย กรองตามจังหวัด อายุ เพศ ระยะการทดลอง | ระบบแปลงคำภาษาไทยเป็นคำค้นภาษาอังกฤษ (`src/lib/thai-terms.ts`) แล้วจับคู่กับชื่อเรื่อง โรค และยาของแต่ละงาน |
| `/trials/[NCT]` รายละเอียด | อ่านสรุปงานวิจัย เกณฑ์รับสมัคร และช่องทางติดต่อ | แยกเกณฑ์คัดเข้า/คัดออกเป็นรายการให้ติ๊กเช็กเอง และให้ Claude อธิบายเป็นภาษาไทยง่ายๆ (ถ้าตั้งค่า API key) |
| `/screen` คัดกรองเบื้องต้น | ตอบอายุ เพศ จังหวัด โรคที่เป็น แล้วดูว่างานไหนน่าจะเหมาะ | ให้คะแนนตามโรคที่ตรงกัน ระยะทาง (จังหวัด/ภาค) อายุ และเพศ (`screenMatch` ใน `src/lib/search.ts`) คำตอบเก็บในเบราว์เซอร์เท่านั้น |
| `/map` แผนที่ | ดูโรงพยาบาลและศูนย์วิจัยที่เปิดรับ เลือกที่ใกล้บ้าน | Leaflet + OpenStreetMap ใช้พิกัดจากทะเบียน ถ้าไม่มีพิกัดจะใช้ตำแหน่งตัวจังหวัด และมีปุ่ม “ใกล้ฉัน” |
| `/alerts` แจ้งเตือน LINE | รับข้อความเมื่อมีงานวิจัยใหม่ในหัวข้อที่สนใจ | LINE Messaging API: พิมพ์ “ติดตาม เบาหวาน เชียงใหม่” ในแชท แล้วงาน cron จะส่งงานวิจัยที่เพิ่งเปิดรับให้ |
| `/learn` ก่อนเข้าร่วม | รู้สิทธิ์ของอาสาสมัคร คำถามที่ควรถาม และสัญญาณเตือน | เนื้อหาคงที่ |

### ฝั่งนักวิจัย
| หน้า | ใช้ทำอะไร |
| --- | --- |

## เทคโนโลยี
- **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS 4**
- **ClinicalTrials.gov API v2**: แหล่งข้อมูล (`src/lib/ctgov.ts`)
- **Leaflet + OpenStreetMap**: แผนที่
- **Recharts**: กราฟในแดชบอร์ด
- **Claude API** (`@anthropic-ai/sdk`): อธิบายงานวิจัยเป็นภาษาไทย (ไม่บังคับ)
- **LINE Messaging API**: แจ้งเตือน (ไม่บังคับ)
- **Vercel**: โฮสต์เว็บ

## การไหลของข้อมูล
1. ดึงทุกงานวิจัยที่มี location = Thailand จาก API ทีละ 1,000 รายการ (ประมาณ 4,400 งาน ใช้เวลาราว 12 วินาที)
2. เก็บเฉพาะศูนย์วิจัยในไทย แล้วแปลงชื่อเมือง/จังหวัด/พิกัด/ชื่อโรงพยาบาลเป็น 77 จังหวัด (`src/lib/provinces.ts`)
3. แคชไว้ในหน่วยความจำและไฟล์ `.cache/trials.json` นาน 12 ชั่วโมง (`CACHE_TTL_HOURS`) เมื่อแคชหมดอายุ ระบบจะส่งข้อมูลเดิมให้ผู้ใช้ก่อน แล้วดึงข้อมูลใหม่อยู่เบื้องหลัง
4. ตอน build (`prebuild`) จะดึงข้อมูลชุดแรกเก็บไว้ในไฟล์ทุกครั้ง ทำให้เปิดหน้าแรกบน Vercel ได้ทันที
5. หน้ารายละเอียดของแต่ละงานจะดึงข้อมูลเต็มจาก `/api/v2/studies/{NCT}` ตอนที่มีคนเปิด

## รันบนเครื่อง
```bash
npm install
cp .env.example .env.local   # ใส่ key เพิ่มเติมถ้าต้องการ
npm run sync                 # ดึงข้อมูลชุดแรก (ไม่บังคับ)
npm run dev
```

## ตัวแปรสภาพแวดล้อม
ดูรายละเอียดใน `.env.example`
- `ANTHROPIC_API_KEY`: เปิดปุ่ม “อธิบายเป็นภาษาไทยด้วย AI”
- `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN`, `NEXT_PUBLIC_LINE_OA_ID`: เปิดใช้การแจ้งเตือนผ่าน LINE
- `CRON_SECRET`: รหัสสำหรับเรียก `/api/cron/notify`
- `NEXT_PUBLIC_SITE_URL`: URL ของเว็บ ใช้ในข้อความที่ส่งทาง LINE

## ตั้งค่า LINE
1. สร้าง Messaging API channel ใน LINE Developers Console
2. ตั้ง Webhook URL เป็น `https://<โดเมน>/api/line/webhook` และเปิด “Use webhook”
3. ใส่ secret, access token และ Basic ID ใน environment variables
4. ตั้ง cron (เช่น Vercel Cron หรือ GitHub Actions) ให้เรียก `GET /api/cron/notify` พร้อม header `Authorization: Bearer $CRON_SECRET` วันละครั้ง

> รายชื่อผู้ติดตามตอนนี้เก็บเป็นไฟล์ JSON (`src/lib/store.ts`) ซึ่งเหมาะกับเซิร์ฟเวอร์เดียว ถ้าจะใช้งานจริงบน serverless ควรเปลี่ยนไปใช้ฐานข้อมูล เช่น Postgres หรือ Redis

## ข้อควรทราบ
- ไม่ใช่คำแนะนำทางการแพทย์ ทีมวิจัยเป็นผู้ตัดสินว่าใครเข้าเกณฑ์
- ข้อมูลมาจาก ClinicalTrials.gov เท่านั้น งานวิจัยที่ลงทะเบียนเฉพาะใน TCTR (Thai Clinical Trials Registry) จะยังไม่ปรากฏ
- ศูนย์วิจัยบางแห่งในทะเบียนไม่ระบุชื่อ (เช่น “Research Site”) จะแสดงเป็น “ศูนย์วิจัย (ไม่ระบุชื่อ)”
